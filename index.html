이 도구의 역할

동의서를 대신 작성하거나 환자가 혼자 보는 교육 페이지가 아닙니다.
의료진이 환자별 정보를 바탕으로 설명 순서와 확인할 위험을 정리하고, 필요한 그림·영상만 환자에게 보여주는 설명 보조 화면입니다.

공용 자료실

자료를 한 번 모아두면 모든 환자 케이스에서 함께 사용합니다. 질환·위치·술식에 맞는 자료를 자동으로 골라옵니다.

교육 자료와 추천 피드백은 이 브라우저에 보관합니다. 다른 컴퓨터에서 사용하려면 자료 포함 HTML을 다운로드하세요. 환자 입력·환자 영상·설명 메모는 포함되지 않습니다.

외부 자료목록 연결 · GitHub Pages

양식과 같은 JSON 자료목록을 읽어 등록합니다. 외부 서버는 브라우저 접근(CORS)을 허용해야 합니다. 인터넷 전체나 논문 사이트를 자동 검색하는 기능은 아닙니다.

JSON의 상대 파일 경로는 자료목록 주소를 기준으로 해석합니다. HTML을 index.html로 올리고 media 폴더와 자료목록을 같은 저장소에 둘 수 있습니다. 영상 주소는 실제 미디어 파일 주소여야 합니다.

위치별 합병증 · 텍스트 참고

위치별 위험은 관련 혈관·신경 손상 시 나타날 수 있는 항목입니다. 발생 확률이나 해당 환자의 발생 여부를 예측하지 않습니다. 기존 증상과 치료 후 새로 발생하는 증상을 구분해 설명하세요.
